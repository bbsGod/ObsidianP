## 模块三 · TCP

（8）TIME_WAIT 等待 **________**（2MSL）才进入 CLOSED：确保最后一个 ACK 能到达（丢了对方会重发 FIN），并让旧连接报文失效。⭐⭐⭐ [来源：资料 面渣逆袭 `2MSL`]

（10）TCP 保证可靠性的机制：**序列号 + 确认应答**、**________**（超时重传）、校验和、流量控制、拥塞控制。⭐⭐⭐ [来源：资料 面渣逆袭 `超时重传`]

（11）MSS（最大报文段长度）是 TCP 握手时**协商**的**________**（最大报文段大小），避免 IP 分片。⭐⭐ [来源：资料 面渣逆袭 `MSS`]

（13）滑动窗口：接收方通过**窗口大小**告知发送方还能接收多少数据，实现**________**（流量控制）。⭐⭐ [来源：资料 面渣逆袭 `流量控制`]
