## 建议学习顺序

按**依赖关系 + 面试提问频率**排，与生成顺序不同：

1. **004 Java基础** — 集合、String、异常、反射、Lambda 是所有模块的地基

4. **001 Spring家族** — IOC / AOP / 事务 / Boot，框架层，前面基础打好了很好懂
5. **003 Tomcat** — HTTP / TCP / SpringMVC，容器与网络收尾
