# 典型回答

  

这个问题，其实不难，主要是大家在回答的时候容易忽略一个点，那就是消息不只是堆积的这部分，还需要考虑新生产出来的消息。

​  

那么，计算扩容规模的时候，就需要知道以下信息：

​  

消息堆积数量：假设值1000万。

目标恢复时间：1小时 = 3600秒。

单消费者处理能力：就是每台机器现在一秒能处理多少消息，这个需要根据现在的消费情况来统计，假设是500/秒吧。

当前新消息生产速率：这个也需要做统计，假设1000/秒。

​  

那么就需要这么算：

​  

1、已积压消息都消费完需要速率：10000000/3600 = 2777/秒

2、加上每秒生产的消息： 1000+2777 = 3777/秒

3、所需消费者总数：3777/500 约等于 8

4、减去当前已有机器数（假设3台）：8-3= 5 。

​  

最终得出需要扩容5台机器。

​  

不过，如果是kafka的话，需要注意，在4.0之前，消费者数如果超过分区数的话，多出来的消费者**无法分配到任何分区**，它们会闲置，处于**空转状态**。需要考虑针对topic进行扩容。
