# 通用提问模板（让模型基于画布生成「补充知识点」+「总预习讲义」）

> 📌 用途：换新对话时，把下面「===== 模板开始 =====」到「===== 模板结束 =====」之间的内容复制给模型，
> 然后把【】里的占位符替换成你的实际内容，模型就会基于你的画布文件生成两个文档。
> 适配任何主题：JVM、多线程、Spring、MySQL、Redis…… 只改【主题名】和【路径】即可。

---

===== 模板开始 =====

我整理了【主题名】的学习笔记，在 Obsidian 画布文件 `【画布完整路径】` 里，有一个「【主题名】」分组，里面是文字卡片和图片截图。

**⚠️ 重要：这个分组里有大量图片截图，图片里存的是笔记文字内容（知识点、表格、代码、参数说明）。你必须把这些图片全部读一遍、识别出里面的文字，作为笔记内容的一部分来理解，不能跳过、不能只读文字卡片。**

请只读这个分组，按下面两步来做：

**第一步：先给结构大纲，别急着写正文。**
你先读一遍我的笔记（含所有图片里的文字），然后告诉我：
- 这个主题应该分成哪几个知识大块；
- 每个大块下有哪些重点知识点；
- 哪些地方我笔记里【缺了、记错了、只记了标题没展开】。
把这份结构大纲列给我，等我确认后，你再进行第二步。

**第二步：我确认大纲后，生成两个 Markdown 文档：**

**文档一《【主题名】补充知识点》** —— 只补我笔记里【缺的、记错的、只有标题没展开】的部分，要求：
- 每个补充点都写清三件事：这是什么（定义）→ 为什么重要（面试/实战价值）→ 怎么记（记忆钩子或一句话总结）；
- 按优先级排序，把「高频必考 + 我笔记最薄弱」的放最前面，用 ⭐⭐⭐/⭐⭐/⭐ 标重要性；
- 如果发现我笔记里记错的知识点，单独开一个「纠错清单」小节，用「❌ 错误认知 → ✅ 正确结论」的对照格式列出来；
- 能用表格对比的（几种算法、几个参数、几种场景、几个版本）就用表格；
- 每块开头用一句话点明"你画布里原来只记了 XX，这里补全"，和我笔记衔接起来。

**文档二《【主题名】总预习讲义》** —— 这个主题【全部重点】的总纲，要求：
- 分单元组织，单元从「基础概念」递进到「核心机制」再到「实战/进阶」；
- 每个知识点划重点（加粗关键词），用 ⭐⭐⭐/⭐⭐/⭐ 标重要性；
- 结论先行：每个小节先给一句"人话总结"，再展开细节；
- 易混淆的概念（几种算法、几个版本、几种方案）用对照表；
- 末尾附一个「一分钟速记卡」，十几条，覆盖这个主题 80% 的高频考点，方便考前扫一眼；
- 语言直白、适合学生预习，先讲"是什么、为什么"再讲"怎么用"，别堆术语。

**两个文件的分工要清楚**：补充知识点 = 只补漏（画布里没有的），总预习讲义 = 全集（覆盖全部重点）。讲义是骨架，补充文档是填缝，两个文件的内容不要重复。

**最后**：把这两个文件保存为 Markdown，放到 `【目标保存目录路径】` 里。

## 怎么用（三步）

1. **打开这个文件**，复制「模板开始」到「模板结束」之间的内容。
2. **替换占位符**：
   - 【主题名】→ 比如「JVM」「Spring」「多线程」
   - 【画布完整路径】→ 比如 `D:\Works\Interview\004-ObsidianCanvas\ObsidianP\Java\多线程并发.canvas`
   - 【目标保存目录路径】→ 比如 `D:\Works\Interview\004-ObsidianCanvas\ObsidianP\Java\GLM\01jvm`
3. **粘贴到新对话**发给模型。
