## 目录结构与答案版格式（2026-11-20 定稿）

## 画布大批量图片读取方法（可复用）
- PIL(需 `python -m pip install pillow`) 定位目标 group 几何范围 → 按最小包含分组归属图片 → 每组按 (y,x) 排序纵向拼接（宽≤1400、高≤3400、每图上方蓝色编号条）→ ViewImage 逐张转录；用完删除临时拼图目录。
- **坑：`type=file` 节点可能指向 `.md` 讲义而非图片**（如 JVM 分组的 `02-JVM补充知识点.md`）。拼图前必须按扩展名过滤（.png/.jpg/...），否则 Pillow 抛 `UnidentifiedImageError`；讲义单独 Read，按 `[来源：外部 讲义名·知识点]` 标注，不伪装成画布内容。
